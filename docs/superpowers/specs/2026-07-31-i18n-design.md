# 国际化 (i18n) 设计方案

**日期：** 2026-07-31
**状态：** 设计中
**作者：** Claude Code

## 概述

为 Hermes Active 前端添加中英文切换功能，支持完全国际化，默认语言为中文。

## 技术选型

- **vue-i18n@9**：Vue 3 官方国际化插件
- **按页面拆分翻译文件**：每个页面一个 JSON 文件
- **后端持久化**：语言偏好存储在 active.db 的 config 表中

## 语言切换 UI

**位置：** Config.vue 的"基础配置" Tab 中，在"个性化设置"卡片之后添加"语言设置"卡片

**UI 组件：**
```vue
<!-- 语言设置 -->
<n-card title="语言设置" style="margin-bottom: 16px">
  <n-form label-placement="left" label-width="100">
    <n-form-item label="界面语言">
      <n-select
        v-model:value="currentLocale"
        :options="localeOptions"
        @update:value="changeLocale"
      />
    </n-form-item>
  </n-form>
</n-card>
```

**选项：**
- `zh-CN`：简体中文（默认）
- `en-US`：English

**交互流程：**
1. 用户选择语言后，立即切换 UI 语言
2. 同时将语言偏好保存到后端 `/config/set?key=locale&value=en-US`
3. 下次登录时自动加载保存的语言偏好

**Naive UI 联动：**
- 在 `main.js` 中配置 Naive UI 的 locale 属性
- 根据当前语言动态加载对应的 Naive UI 语言包

## 翻译文件结构

**翻译 key 命名规范：** 使用 `页面名.组件名.字段名` 的格式

**示例 - 登录页面 (login.json)：**
```json
{
  "login": {
    "title": "{name}的控制台",
    "username": "用户名",
    "password": "密码",
    "submit": "登 录",
    "footer": "v0.1.0 · by {name}",
    "welcome": [
      "今天也要元气满满哦 ✨",
      "等你好久了，快来呀~",
      "想你了，终于来啦 ❤️"
    ]
  }
}
```

**示例 - 侧边栏 (common.json)：**
```json
{
  "sidebar": {
    "dashboard": "监控面板",
    "sessions": "会话管理",
    "messages": "消息管理",
    "passiveConsciousness": "被动意识",
    "activeConsciousness": "主动意识",
    "freeConsciousness": "自由意识",
    "config": "配置管理",
    "cronJobs": "定时任务",
    "taskLogs": "任务日志",
    "systemLogs": "系统日志",
    "test": "测试工具",
    "keyTest": "Key测试",
    "logout": "退出登录"
  }
}
```

**使用方式：**
```vue
<!-- 模板中 -->
{{ $t('sidebar.dashboard') }}

<!-- 带参数 -->
{{ $t('login.title', { name: globalConfig.assistant_name }) }}

<!-- 脚本中 -->
const { t } = useI18n()
t('sidebar.dashboard')
```

## 错误处理

**翻译缺失处理：**
- 如果某个翻译 key 不存在，vue-i18n 默认显示 key 本身
- 开发环境下在控制台输出警告

**语言切换时机：**
- 切换语言时，所有已渲染的组件自动响应式更新
- Naive UI 组件（如分页、空状态）同步切换

**后端配置加载失败：**
- 如果后端加载语言配置失败，使用默认值 `zh-CN`
- 不阻塞应用启动

**浏览器语言检测：**
- 首次访问时，如果后端没有保存的语言偏好，检测浏览器语言
- 如果浏览器语言是中文（zh-*），使用 `zh-CN`
- 如果浏览器语言是英文（en-*），使用 `en-US`
- 其他语言默认使用 `zh-CN`
