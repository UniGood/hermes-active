## 改动清单

### 1. 主动意识 - 情绪系统(行 212–229)

**修正**:将"融合权重不是固定的:置信度评分……会让混合比例在 0.7/0.3 到 0.3/0.7 之间动态移动"改为三档分段跳变。

**补充**:
- 情绪演化三公式(用文字 + 公式表达):
  - 唤醒度衰减:`arousal' = max(0.1, arousal - decay_rate × hours)`,下限 0.1,默认 `decay_rate=0.02`/小时
  - 社交需求增长:`social_need' = min(1.0, social_need + social_need_growth × hours)`,上限 1.0,默认 `social_need_growth=0.01`/小时
  - 效价回归中性:`valence' = valence + (0.5 - valence) × valence_regression × hours`,默认 `valence_regression=0.1`/小时
- 置信度计算公式(基础 0.5 + 合理性 0.2 + 一致性 0.3 - 离群 0.2)
- 三档融合权重表(置信度 <0.3 / 0.3–0.8 / >0.8 对应 0.7·0.3 / 0.4·0.6 / 0.3·0.7)
- 主导情绪 9 级阈值表(优先级从上到下:yearning/anxious/longing/missing/calm/happy/content/bored/concerned)
