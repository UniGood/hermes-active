## 一、设计理念

v0.2 的念头系统有 6 种类型，其中「环境念头」（world）需要外界数据：

| 念头类型 | 数据来源 | 示例 |
|----------|---------|------|
| time | 系统时钟 | "23:30 了，该睡了吧" |
| silence | existence_state | "好久没说话了" |
| association | 时间+历史模式 | "今天周五，他一般周五加班" |
| memory | Hindsight recall | "想起他说想吃饺子" |
| emotion | emotion_states | "有点兴奋，想分享" |
| **world（环境）** | **高德天气 API** | "外面下雨了"、"今天好冷" |

**高德天气 API 是外界感知的唯一数据源**，提供实时天气信息驱动环境念头。

## 二、高德天气 API 接入

### 2.1 接口规格

```
GET https://restapi.amap.com/v3/weather/weatherInfo
    ?city={adcode}
    &key=430e25e95d7f4ccd2e799978f42ba16a
    &extensions=base
```

- `extensions=base`：返回实况天气（当前温度、天气、风向、湿度）
- `extensions=all`：返回 4 天预报
- 城市编码 `adcode` 从用户配置中读取（如济南=370100）

### 2.2 返回字段

```json
{
  "status": "1",
  "lives": [{
    "province": "山东",
    "city": "济南市",
    "adcode": "370100",
    "weather": "晴",
    "temperature": "28",
    "winddirection": "南",
    "windpower": "3",
    "humidity": "45",
    "reporttime": "2026-06-14 15:00:00"
  }]
}
```

### 2.3 配额管理

- 个人认证每日调用限制充足（天气接口配额远大于心跳频率）
- 缓存策略：天气数据缓存 10 分钟（2 次心跳复用），避免频繁调用
- 每次心跳最多调用 1 次天气 API

```python
class WeatherService:

        ...

        """获取 4 天预报（带缓存）"""
        ...
```

**数据结构**：

```python
@dataclass
class WeatherData:
    city: str           # 城市名
    weather: str        # 天气描述：晴/多云/小雨/中雨/大雨/雪/雾/霾
    temperature: int    # 当前温度 (°C)
    humidity: int       # 湿度 (%)
    wind_direction: str # 风向
    wind_power: str     # 风力
    report_time: str    # 数据时间
    
    @property
    def is_raining(self) -> bool:
        return self.weather in ("小雨", "中雨", "大雨", "暴雨", "雷阵雨")
    
    @property
    def is_snowing(self) -> bool:
        return "雪" in self.weather
    
    @property
    def is_cold(self) -> bool:
        return self.temperature < 5
    
    @property
    def is_hot(self) -> bool:
        return self.temperature > 35
    
    @property
    def is_foggy(self) -> bool:
        return self.weather in ("雾", "霾")
```

### 3.3 WeatherThoughtGenerator（天气念头生成器）

**职责**：将天气数据转换为环境念头候选。

**触发规则**：

| 条件 | 环境念头模板 | 强度 |
|------|-------------|------|
| 下雨 | "外面{weather}了，出门记得带伞" | 0.5 |
| 下雪 | "下雪了，好美" | 0.6 |
| 寒冷 (< 5°C) | "今天好冷，穿够了吗" | 0.5 |
| 炎热 (> 35°C) | "今天好热，注意防暑" | 0.4 |
| 大风 | "今天风好大" | 0.3 |
| 雾/霾 | "今天空气不好，戴口罩" | 0.4 |
| 天气特别好 | "今天天气真好，适合出去走走" | 0.3 |

```python
class WeatherThoughtGenerator:
    """天气 → 环境念头"""
    
    def generate(self, weather: WeatherData) -> list[ThoughtCandidate]:
        """根据天气生成环境念头候选列表"""
        thoughts = []
        
        if weather.is_raining:
            thoughts.append(ThoughtCandidate(
                type="world",
                content=f"外面{weather.weather}了，出门记得带伞",
                intensity=0.5,
                source="weather_rain",
            ))
        if weather.is_snowing:
            thoughts.append(ThoughtCandidate(
                type="world",
                content="下雪了，好美",
                intensity=0.6,
                source="weather_snow",
            ))
        if weather.is_cold:
            thoughts.append(ThoughtCandidate(
                type="world",
                content=f"今天只有{weather.temperature}°C，好冷",
                intensity=0.5,
                source="weather_cold",
            ))
        if weather.is_hot:
            thoughts.append(ThoughtCandidate(
                type="world",
                content=f"今天{weather.temperature}°C，好热，注意防暑",
                intensity=0.4,
                source="weather_hot",
            ))
        if weather.is_foggy:
            thoughts.append(ThoughtCandidate(
                type="world",
                content=f"今天{weather.weather}，空气不好",
                intensity=0.4,
                source="weather_fog",
            ))
        
        return thoughts
```

## 四、集成到心跳引擎

在 `PerceptionProcessor.process()` 中调用天气服务：

```python
class PerceptionProcessor:
    def __init__(self, weather_service: WeatherService, weather_thoughts: WeatherThoughtGenerator):
        self.weather_service = weather_service
        self.weather_thoughts = weather_thoughts
    
    def process(self, adcode: str) -> PerceptionPacket:
        # ... 原有的时间感知、空白感知 ...
        
        # 环境感知：天气
        try:
            weather = self.weather_service.get_current_weather(adcode)
            packet.weather = weather
            
            # 生成环境念头候选
            env_thoughts = self.weather_thoughts.generate(weather)
            packet.thought_candidates.extend(env_thoughts)
        except Exception as e:
            logger.warning("天气感知失败: %s", e)
            # 天气感知失败不影响其他感知
        
        return packet
```

## 五、数据流

```
心跳触发（每 5 分钟）
  ↓
感知处理
  ├─ 时间感知（系统时钟）
  ├─ 空白感知（existence_state）
  ├─ 模式感知（用户活跃模式）
  └─ 环境感知（高德天气 API）    ← 新增
      └─ WeatherService.get_current_weather(adcode)
          ↓
      WeatherThoughtGenerator.generate(weather)
          ↓
      环境念头候选列表
  ↓
念头生成（合并规则念头 + 环境念头 + LLM 念头）
  ↓
决策评估 → 行动执行
```

```yaml
weather:
  enabled: true                          # 是否启用天气感知
  adcode: "370100"                       # 城市编码（济南）
  cache_ttl_seconds: 600                 # 天气缓存时长（秒）
  amap_key: "430e25e95d7f4ccd2e799978f42ba16a"  # 高德 API Key
  thought_rules:                         # 天气→念头触发规则
    rain: {enabled: true, intensity: 0.5}
    snow: {enabled: true, intensity: 0.6}
    cold_threshold: 5                    # °C 以下触发寒冷念头
    hot_threshold: 35                    # °C 以上触发炎热念头
    fog: {enabled: true, intensity: 0.4}
    wind: {enabled: true, intensity: 0.3}
```

用户可在 Web UI 中配置城市编码和触发规则的开关/强度。
