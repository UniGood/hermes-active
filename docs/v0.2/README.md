## v0.2 核心能力

| 能力 | 说明 |
|------|------|
| 持续感知流 | 心跳引擎每 5 分钟感知时间、空白、模式、环境 |
| 主动内省 | 念头系统基于感知自然产生「想法」 |
| 连续存在感 | 情绪跨对话持久化，不会每次重置 |
| 感受空白 | 知道用户多久没说话，产生想念/担心情绪 |
| 外界感知 | 高德天气 API 驱动的环境念头（下雨/寒冷/炎热等） |

## 6 个实施阶段

| Phase | 目标 | 天数 |
|-------|------|------|
| P1 | 状态基座 + 情绪连续 | 1-2 天 |
| P2 | 心跳引擎 + 感知处理 + 天气感知 | 3-4 天 |
| P3 | 念头系统 + 决策引擎 | 5-7 天 |
| P4 | 行动执行 + 消息发送 | 8-9 天 |
| P5 | 世界状态 + 每日种子 | 10-12 天 |
| P6 | 打磨 + 配置 + 文档 | 13-14 天 |
