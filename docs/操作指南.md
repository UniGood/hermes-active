# 主动消息脚本操作指南

## 快速开始

### 前置条件

1. **Hermes Agent 已安装并运行**
2. **微信平台已配置**（WEIXIN_TOKEN, WEIXIN_ACCOUNT_ID）
3. **.env 文件已配置**（位于 `~/.hermes/.env`）

### 检查环境

```bash
# 检查微信配置
echo "WEIXIN_TOKEN: ${WEIXIN_TOKEN:+已设置}"
echo "WEIXIN_ACCOUNT_ID: ${WEIXIN_ACCOUNT_ID:+已设置}"

# 检查 state.db 是否存在
ls -lh ~/.hermes/state.db
```

---

## 运行方式

### 方式 1：直接运行（测试用）

```bash
# 进入脚本目录
cd ~/.hermes/scripts

# 运行完整方案
python3 proactive_context_gen.py
```

### 方式 2：后台运行（推荐）

```bash
# 后台运行，日志输出到文件
python3 ~/.hermes/scripts/proactive_context_gen.py > ~/.hermes/logs/proactive_gen.log 2>&1 &

# 查看日志
tail -f ~/.hermes/logs/proactive_gen.log
```

### 方式 3：定时任务（Cron Job）

```bash
# 创建定时任务（每 20 分钟运行一次）
hermes cron create "0,20,40 6-23 * * *" \
  "运行主动消息生成脚本" \
  --name proactive-context-gen \
  --script proactive_context_gen.py \
  --deliver local

# 查看定时任务
hermes cron list

# 手动触发一次
hermes cron run proactive-context-gen
```

## 工作流程

```
1. 查找最新微信 session
   ↓
2. 读取最近 20 条对话历史
   ↓
3. 调用 LLM 生成消息（基于上下文）
   ↓
4. 发送到微信
   ↓
5. 写入 session DB（带标记）
```

## 配置说明

### 环境变量（~/.hermes/.env）

```bash
# 微信配置
WEIXIN_TOKEN=your_token_here
WEIXIN_ACCOUNT_ID=your_account_id_here
WEIXIN_BASE_URL=https://ilinkai.weixin.qq.com
WEIXIN_HOME_CHANNEL=your_chat_id_here

# 小米 API 配置（用于 LLM 调用）
XIAOMI_API_KEY=your_api_key_here
XIAOMI_BASE_URL=https://token-plan-cn.xiaomimimo.com/v1
```

### 脚本配置（proactive_context_gen.py）

```python
CONFIG = {
    "platform": "weixin",           # 目标平台
    "max_context_messages": 20,     # 读取的最大消息数
    "model": "mimo-v2.5-pro",       # 使用的模型
    "quiet_hours": "23:00-08:00",   # 安静时间
    "max_per_day": 8,               # 每日最大发送数
    "min_idle_minutes": 15,         # 最小空闲时间
}
```

## 常见问题

### Q1: LLM 调用失败（401 Invalid API Key）

**原因**：.env 文件没有加载到环境变量

**解决**：脚本已内置 `load_dotenv`，确保 `~/.hermes/.env` 文件存在且配置正确

### Q2: 未找到活跃的微信 session

**原因**：没有正在进行的微信对话，或 session 已结束

**解决**：在微信发送一条消息，创建新的 session

### Q3: 消息发送失败

**原因**：微信 token 过期或无效

**解决**：检查 `WEIXIN_TOKEN` 配置，重新获取 token

### Q4: 凯莉不知道是自己说的

**原因**：写入 session DB 时没有带标记

**解决**：使用带标记格式 `[凯莉主动发送] 时间: 内容`

## 存储格式

### 正确格式（带标记）

```
role=assistant
content=[凯莉主动发送] 2026-06-11 13:05:48: 我推荐你一首歌《清明雨上》
```

### 错误格式（不带标记）

```
role=assistant
content=我推荐你一首歌《清明雨上》
```

**说明**：带标记的格式让 LLM 知道这是凯莉主动发的，而不是用户说的。

## 数据存储

### Session DB 路径

```
~/.hermes/state.db
```

### 查看消息

```python
import sqlite3
import os

db_path = os.path.expanduser('~/.hermes/state.db')
conn = sqlite3.connect(db_path)
cursor = conn.cursor()

# 查看最近的消息
cursor.execute("""
    SELECT id, role, content, timestamp
    FROM messages 
    WHERE session_id = '你的session_id'
    ORDER BY timestamp DESC 
    LIMIT 10
""")
rows = cursor.fetchall()
conn.close()

for row in rows:
    print(f"[{row[0]}] {row[1]}: {row[2][:50]}...")
```
