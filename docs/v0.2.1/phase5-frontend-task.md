## 实现要点

1. **弹窗全屏**：使用 `style="width: 95vw; max-width: 1200px"` 或 fullscreen 属性
2. **数据兼容**：兼容新旧两种 details 格式（v0.2 和 v0.2.1）
3. **情绪标签颜色**：
   - happy/content → success (绿色)
   - longing/missing/yearning → warning (橙色)
   - anxious/concerned → error (红色)
   - calm/bored → default (灰色)
4. **念头类型标签颜色**：
   - emotion → success
   - memory → info
   - silence → warning
   - time → default
   - env → info
   - assoc → default
5. **Hindsight 标签**：使用 n-tag 组件，不同标签不同颜色
