3. 数据流 — 谁读谁写
数据源 读取方 写入方 内容
state.db sessions hermes-active（查活跃session） hermes-agent / Gateway 会话信息（platform, user_id, ended_at）
state.db messages hermes-active（查最近消息、统计发送数） hermes-agent / hermes-active 消息内容（role, content, timestamp）
active.db configs hermes-active（读配置、读情绪值） hermes-active（写配置、写情绪值） 所有配置项 + 运行时状态（emotional_intensity）
active.db active_heartbeat_logs 前端（展示心跳历史） hermes-active（run_heartbeat） 心跳执行记录（时长、情绪、决策、详情）
active.db active_thought_logs 前端（展示念头历史） hermes-active（generate_thought） 念头记录（内容、类型、强度、决策）
Hindsight hermes-active（recall/reflect） hermes-agent（对话时自动retain） 长期记忆（语义检索 + 综合分析）
LLM hermes-active（生成想法、评估情绪） — 生成自然语言 + 情绪评分
微信/飞书 — hermes-active（MessageService） 主动发送的消息
4. 配置项 — 所有阈值可配置
配置 key 默认值 说明
active_consciousness.enabled false 总开关
active_consciousness.active.heartbeat_interval 600 心跳间隔（秒）
active_consciousness.active.cooldown_minutes 30 发送冷却期（分钟）
active_consciousness.active.no_send_after_user_msg_minutes 10 用户消息后多久不发送
active_consciousness.decision.send_threshold 0.6 情绪值阈值（超过则发送）
active_consciousness.decision.max_per_hour 2 每小时最大发送数
active_consciousness.decision.max_per_day 5 每日最大发送数
active_consciousness.decision.longing_gap_threshold 3 想念等级阈值（超过则gap_send）
active_consciousness.session.sources ["weixin"] 监听的消息来源
active_consciousness.hindsight.enabled true 是否启用 Hindsight 记忆

心跳闭环

  • APScheduler 按间隔触发
  • 查 state.db 计算想念/热度
  • 评估情绪值（规则+LLM）
  • 决策是否发送
  • 生成想法 → 发送 → 记录日志

数据隔离

  • state.db — 只读，hermes-agent 维护
  • active.db — 读写，hermes-active 维护
  • 情绪值存在 configs 表（运行时状态）
  • 日志存在 active_*_logs 表
